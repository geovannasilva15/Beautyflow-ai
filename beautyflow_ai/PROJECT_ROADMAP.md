# Roadmap do BeautyFlow AI

## Fase 1 - MVP local
- Rodar FastAPI + Streamlit.
- Cadastrar clientes, serviços e agendamentos.
- Testar recomendador de serviços.
- Testar assistente IA e gerador de mensagens.

## Fase 2 - Produto para portfólio
- Criar landing page explicando o projeto.
- Criar prints do dashboard.
- Publicar código no GitHub.
- Escrever README com problema, solução, tecnologias e próximos passos.
- Criar vídeo curto mostrando o funcionamento.

## Fase 3 - Produto real
- Adicionar autenticação.
- Migrar banco para PostgreSQL.
- Criar integração com WhatsApp Cloud API.
- Criar agenda com bloqueios de horário.
- Adicionar pagamento/sinal de reserva.
- Adicionar painel financeiro.
- Criar app mobile.

## Fase 4 - IA avançada
- Prever risco de no-show.
- Segmentar clientes automaticamente.
- Recomendar campanhas por horário ocioso.
- Criar análise de imagens com consentimento.
- Criar RAG com documentos internos do negócio.
